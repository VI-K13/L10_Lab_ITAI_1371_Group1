## Overview

This lab explores unsupervised learning through two techniques: K-Means Clustering and Principal Component Analysis (PCA). The goal is to understand how machine learning can identify patterns without target labels and reduce the number of features in a dataset while preserving most of its variance.

## Lab Tasks

**Task 1 – Elbow Method (Tien Manh Nguyen)**
- Applied K-Means with k values from 1 to 10.
- Calculated and plotted inertia to identify the optimal number of clusters.

**Task 2 – K-Means Clustering (Viktoriya Kurmisheva)**
- Applied K-Means using four clusters.
- Visualized the clusters and their centroids using a scatter plot.

**Task 3 – Principal Component Analysis (Zaid Alayedy)**
- Applied PCA to the Iris dataset.
- Reduced four features to two principal components.
- Visualized the results and calculated the explained variance.

## Results

- **K-Means:** The Elbow Method suggested four clusters as the optimal choice.
- **PCA:** The first two principal components explained approximately 97.77% of the total variance.
